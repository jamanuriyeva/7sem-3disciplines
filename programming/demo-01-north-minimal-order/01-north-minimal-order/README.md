
# Курсовой проект: Билеты на мероприятие (Стадия 01)

Контекст Ordering содержит один агрегат: корень `Order` (в предметной области — Бронь) 
и внутренние сущности `OrderLine` (в предметной области — Билет). 
Корень принимает команды, сохраняет инварианты и выдаёт снимок состояния.

Фабрики создают только допустимые черновики и оплачиваемые строки. 
Прикладная служба координирует вызов одного корня; REST-контроллер переводит HTTP-данные 
в команду и не содержит предметных правил.

## Тема проекта

Система бронирования билетов на мероприятие. 
Позволяет создать бронь, добавить билеты (места), указать ряд/место и подтвердить оплату.
