# Север 00. Процедурная исходная точка

Небольшое приложение хранит товары, корзину, остаток и заказы в одном
изменяемом словаре. Оно выполняет сценарий оформления, однако не выделяет
предметные границы: одна функция одновременно читает каталог, проверяет
остаток, вычисляет сумму и меняет заказ. Эта версия нужна как наблюдаемая
исходная точка перед введением агрегата.

```bash
uv run python -m north_baseline
uv run pytest
```

## Наблюдаемые ограничения

- строка заказа не имеет собственной идентичности;
- цена берётся из каталога прямо в процедуре, поэтому правило снимка не выражено;
- любой вызывающий код может изменить корзину и остаток;
- нет границы, которая владела бы правилами оформления.
